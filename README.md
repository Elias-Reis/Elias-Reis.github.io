# Portfólio · Elias Reis

Site pessoal feito para o projeto final da disciplina de Front-end do curso de Análise e Desenvolvimento de Sistemas (UDF). Apresenta quem eu sou, minhas competências, projetos, currículo, certificados e formas de contato.

**Acesse o site:** https://Elias-Reis.github.io/

## Sobre o projeto

Sou estudante de ADS com foco em engenharia de dados e estou em transição de carreira da confeitaria para a tecnologia. O portfólio reúne o que construí e estudei até aqui, e cresce conforme eu avanço.

### Seções

- **Início:** apresentação e o que estou estudando, construindo e explorando agora.
- **Sobre mim:** minha história, ficha resumida e pontos fortes.
- **Competências:** tecnologias que uso, com o nível de cada uma.
- **Projetos:** [Open-Meteo ETL](https://github.com/Elias-Reis/etl-clima) e o banco de dados de uma cafeteria.
- **Currículo:** versão em página, com link para o PDF.
- **Certificados:** cursos do Certificado Profissional de Engenharia de Dados da IBM.
- **Fora do código:** música, cozinha e projetos faça você mesmo.
- **Contato:** links e formulário (abre o aplicativo de e-mail do visitante).

## Funcionalidades

- Design responsivo, pensado para celular e desktop.
- Modo claro e escuro, com a escolha salva no navegador.
- Janela de ampliação para imagens dos projetos e para os certificados em PDF, sem sair da página.
- Menu adaptado para celular, com indicação da seção atual.
- Validação do formulário de contato em JavaScript.
- Animações leves, que respeitam a preferência de movimento reduzido do sistema.

## Tecnologias

- HTML5
- CSS3 (variáveis, Grid, Flexbox e media queries)
- JavaScript puro, sem frameworks
- Fontes Bricolage Grotesque e Figtree, pelo Google Fonts
- Hospedagem no GitHub Pages

## Como rodar localmente

Não precisa instalar nada. Há duas formas:

1. Abrir o arquivo `index.html` direto no navegador.
2. Ou, para simular um servidor, rodar na pasta do projeto:

```bash
python -m http.server 8000
```

e acessar `http://localhost:8000`.
